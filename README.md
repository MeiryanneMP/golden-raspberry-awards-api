Projeto:
-------------------------------------------------------------------------------------------------------------------
API que retorna lista de produtores com maior intervalo entre dois prêmios consecutivos, e o que obteve dois
prêmios mais rápido da categoria: Pior Filme do Golden Raspberry Awards.

Sistema Operacional:
-------------------------------------------------------------------------------------------------------------------
Windows:

Windows 10 (versão 64 bits) ou superior.

Linux:

Distribuições recentes do Linux, como Ubuntu 20.04 LTS ou superior, CentOS 7 ou superior.

macOS:

macOS 10.15 (Catalina) ou superior.

Requisitos de Software:
-------------------------------------------------------------------------------------------------------------------
Java Development Kit (JDK) 21

IntelliJ IDEA, Eclipse, NetBeans, ou qualquer IDE de sua preferência.

Maven para gerenciamento de dependências e construção do projeto.

Rodando o projeto:
-------------------------------------------------------------------------------------------------------------------
mvn spring-boot:run
